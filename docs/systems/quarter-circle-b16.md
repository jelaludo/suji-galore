# Quarter-Circle B16 · 弧

Quarter-Circle B16 is an experimental additive binary encoding for one hexadecimal digit. Its four quadrant arcs carry the weights 1, 2, 4, and 8:

- upper left = 1
- upper right = 2
- lower left = 4
- lower right = 8

The selected arcs are added. Thus 3 is the upper semicircle, 12 is the lower semicircle, and 15 is a complete ring. Zero is a centre dot.

For values above 15, base-16 places form concentric rings: the units digit is outermost and each inner ring is worth sixteen times the ring outside it. A short top tick marks an empty positional ring so zero places remain perceptible.

The public name replaces the prototype label “Ko,” which did not explain the mechanism. The internal id remains `ko` to preserve links and device-local Study statistics. This notation comes from the sūji-galore build brief and is not presented as a historical system.
