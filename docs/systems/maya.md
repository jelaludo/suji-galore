# Maya numerals · マヤ数字

Dots represent ones, bars represent fives, and a shell represents zero. Digits use base 20 and stack vertically with the most significant place at the top. The current playground implements the regular arithmetic form. It does not yet implement the calendar convention where the third position uses a factor of 18.

The bars and dots use simple native SVG primitives. The zero shell is an original minimal shape informed by the Unicode repertoire rather than copied font geometry.
